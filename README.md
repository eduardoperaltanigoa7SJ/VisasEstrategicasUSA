# Visas Estratégicas USA 🇺🇸

Sitio web profesional para servicios de trámites migratorios y visas americanas.

## 🌟 Características

### Servicios Ofrecidos
- Visa de Turista (B1/B2)
- Visa de Trabajo (H1-B)
- Residencia Permanente (Green Card)
- Visa de Estudiante (F1)
- Visa de Prometido (K1)
- Visa de Inversionista (E2)

### Funcionalidades del Sitio

#### 🤖 Chatbot Inteligente
- Asistente virtual que responde preguntas sobre visas
- Información sobre precios, requisitos y procesos
- Disponible 24/7 para atender consultas

#### 🛒 Carrito de Compras
- Agregar múltiples servicios
- Ver resumen de compra
- Gestionar items del carrito

#### 💳 Opciones de Pago
- Pago único
- 3 meses sin intereses
- 6 meses sin intereses
- 12 meses sin intereses
- Cálculo automático de pagos mensuales

#### 📋 Captura de Leads
- Formulario de contacto completo
- Almacenamiento de datos de clientes
- Seguimiento personalizado

## 🚀 Cómo Usar

### Abrir el Sitio Web
Simplemente abre el archivo `index.html` en tu navegador web:

```bash
# Opción 1: Abrir directamente
open index.html  # macOS
start index.html # Windows
xdg-open index.html # Linux

# Opción 2: Usar un servidor local
python3 -m http.server 8080
# Luego visita: http://localhost:8080
```

### Navegación
- **Inicio**: Información general y hero section
- **Servicios**: Catálogo de servicios con precios
- **Proceso**: Pasos del proceso de asesoría
- **Contacto**: Formulario para captura de leads

### Usar el Chatbot
1. El chatbot se abre automáticamente al cargar la página
2. Escribe tu pregunta en el campo de texto
3. Presiona "Enviar" o Enter
4. Recibe respuestas instantáneas sobre visas

### Comprar Servicios
1. Navega a la sección "Servicios"
2. Haz clic en "Agregar al Carrito" en el servicio deseado
3. Haz clic en el ícono del carrito (🛒)
4. Selecciona tu plan de pago preferido
5. Haz clic en "Proceder al Pago"
6. Completa el formulario de checkout

### Solicitar Consulta
1. Navega a la sección "Contacto"
2. Completa el formulario con:
   - Nombre completo
   - Email
   - Teléfono
   - Servicio de interés
   - Descripción de tu caso
3. Haz clic en "Enviar Consulta"
4. Recibirás confirmación de que tu solicitud fue recibida
